#
#   NAME  KIND  SYMBOL-OR-ADDRESS  [description]
#
# KIND: func  function start, overridden in the runtime (PPC_OVERRIDE(NAME)) or called
#       code  instruction (recompiler patches and probes)

# SYMBOL-OR-ADDRESS: the ELF symbol name, or a hex address (code inside a function)
